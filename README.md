## ⚡ Quick Start & Commands

```bash
# Run all tests in the repository
npm test

# Run tests by module:
npm run test:phase1   # Module 8: Web Foundations & CSS
npm run test:phase2   # Module 9: Core JS & DOM Engine
npm run test:phase3   # Module 10: Async JS & Modern Tooling
npm run test:phase4   # Module 11: React Foundations
npm run test:phase5   # Module 12: Routing & State Architecture
npm run test:phase6   # Module 13: Enterprise State & Capstone

# Run a specific drill in watch mode while you write code:
npx vitest 04-react-foundations/drills/02-stateful-token-counter
```

## 📖 How to Learn with This Dojo

Each module is 100% self-contained so you can learn anytime offline without an AI subscription:
1. **`README.md`**: The complete conceptual textbook explaining the theory, visual mental models, and the "#1 Bug" beginners face. Read this first!
2. **`drills/`**: Focused hands-on exercises with `# TODO` starter stubs and unit tests.
3. **`solutions/`**: Master reference implementations and companion `explanation.md` files dissecting *why* the solution works.
