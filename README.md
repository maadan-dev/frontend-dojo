## ⚡ Quick Start & Commands

```bash
# Run all tests in the repository
npm test

# Run tests specifically for Module 01 (Web Foundations)
npm run test:phase1

# Run tests specifically for Module 02 (Core JS & DOM)
npm run test:phase2

# Run tests for a specific drill in watch mode while you code:
npx vitest 02-core-javascript-and-dom/drills/03-closure-state-machine
```

## 📖 How to Learn with This Dojo

Each module contains:
1. **`README.md`**: The complete conceptual textbook explaining the theory, visual mental models, and the "#1 Bug" beginners face. Read this first!
2. **`drills/`**: Focused hands-on exercises with `# TODO` starter stubs and unit tests.
3. **`solutions/`**: Master reference implementations and companion `explanation.md` files dissecting *why* the solution works.
